Normal Property vs Signal

Normal Property: It stores a value.

If another value is calculated from it, we need to manually recalculate that value when the original value changes.

Example: count = 1, doubleCount = count * 2. If count becomes 2, doubleCount does not automatically become 4.

Signal: It stores a value and Angular tracks its changes.

If another value depends on the Signal using computed(), Angular knows the dependency automatically.

Example: count = signal(1), doubleCount = computed(() => count() * 2).

If count changes from 1 to 2, doubleCount automatically becomes 4.

In short: Normal property → stores value, dependency is not tracked.

Signal → stores reactive value and Angular tracks its dependencies.

computed() → creates a value based on Signals and updates when its dependent Signals change.
