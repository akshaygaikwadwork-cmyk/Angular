Angular Pipes - Notes

Definition: A Pipe is used to transform or format data before displaying it in the HTML.

Syntax: value | pipeName

Why? To display data in a required format without changing the original value.

When? Use Pipes when we need to format or transform data for display.

Types of Pipes

1. Built-in Pipes: Angular provides ready-made Pipes.

uppercase → Converts text to uppercase.

lowercase → Converts text to lowercase.

date → Formats date values.

currency → Formats numbers as currency.

percent → Formats numbers as percentages.

json → Converts an object into JSON text for display/debugging.

2. Custom Pipes: We create our own Pipe when the required transformation is not provided by Angular's built-in Pipes.

Example: pipeShortName → Converts a full name into a short name.

Example: convertPipe → Performs custom currency conversion.

Important

A Pipe normally transforms the value only for display. It does not modify the original value.

In short: Pipe = Transform/format data for display.
