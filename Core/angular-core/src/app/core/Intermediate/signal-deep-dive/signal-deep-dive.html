Angular Signals - Deep Dive

1. Fine-Grained Reactivity

Definition: Fine-grained reactivity means Angular tracks exactly which Signals are used by the UI or other reactive values.

When a Signal changes, Angular updates only the parts that depend on that Signal instead of unnecessarily updating everything.

Example: count and name are separate Signals. If count changes, Angular knows that the UI using count needs to react.

In short: Signal changes → Angular knows what depends on it → update only the required reactive parts.

2. Signal Graph / Dependency Tracking

Signals can form a dependency graph.

Example: doubleCount depends on count2.

count2 → doubleCount

When count2 changes, Angular knows that doubleCount depends on count2 and recalculates doubleCount.

Example: count2 = 2 → doubleCount = 4

If count2 becomes 3 → doubleCount automatically becomes 6.

In short: Signal → computed Signal → updated value.

3. computed()

Definition: computed() creates a derived Signal whose value depends on other Signals.

Example: doubleCount = computed(() => count2() * 2)

When count2 changes, doubleCount automatically recalculates.

In short: computed() = calculate and return a reactive value.

4. effect()

Definition: effect() automatically executes logic when the Signals used inside the effect change.

An effect runs once during initialization and then runs again when its dependent Signals change.

Example: effect(() => console.log(total()))

When count3 or price changes, total changes and the effect runs.

In short: Signal changes → effect() runs → perform some action.

5. Avoid Unnecessary Re-rendering

Signals provide fine-grained reactivity, so Angular can track which parts of the application depend on which Signals.

Example: total depends on both count3 and price.

count3 → total

price → total

If count3 changes, total is recalculated because total depends on count3.

If price changes, total is recalculated because total depends on price.

Angular tracks these dependencies automatically.

Important Difference

Signal: Stores reactive state.

computed(): Creates a derived value from Signals.

effect(): Runs side-effect logic when dependent Signals change.

Fine-grained reactivity: Angular tracks specific dependencies so reactive updates can be targeted instead of unnecessarily affecting unrelated state.

Easy Flow to Remember

Signal changes → dependency is tracked → computed value recalculates → dependent UI/effect reacts
