Effects - Simple Explanation

effect() is used to automatically execute some logic when the Signal values used inside the effect change.

The effect runs once when it is initialized, and then runs again whenever its dependent Signal changes.

Example 1: If count changes, the effect can automatically print the new count value in the console.

Example 2: If isDarkMode changes, the effect can automatically change the document body's background and text color.

Example 3: If message changes, the effect can automatically perform some logic based on the new message.

Important: effect() is mainly used for side effects such as console.log, changing the DOM, localStorage, API calls, or other actions outside the Signal state.

computed vs effect: computed() calculates and returns a new value. effect() executes logic when its dependent Signals change.

In short: Signal changes → effect() automatically runs → perform some action.
