Todo App - Signal Practice

Signal: todoListRecords stores the Todo items as a reactive array.

Add: update() is used to create a new array by keeping the existing items and adding the new item.

Example: [...items, newItem]

Delete: filter() creates a new array without the selected item.

Example: items.filter((_, index) => index !== deleteIndex)

for: Used to loop through the Todo Signal array and display each item.

track $index: Helps Angular track each item in the list using its index.

if: Used to conditionally show the Todo table when items exist and an empty message when there are no items.

Important: When todoListRecords changes, Angular tracks that the template depends on this Signal and updates the affected UI.

In short: Signal → stores Todo list → update() changes the list → Angular reacts → UI updates.
